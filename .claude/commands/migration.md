Измени схему БД: $ARGUMENTS

⚠️ Prisma 7 в этом проекте: клиент генерится в `generated/prisma/`, НЕ в
node_modules. Типы и enum'ы импортятся оттуда. Пропуск регенерации = разъехавшиеся
типы и непонятные ошибки компиляции.

Порядок:
1. Сверься с `PRODUCT.md` (модель данных) — не противоречит ли изменение
   принятым решениям (напр. `totalPrice` фиксируется и не пересчитывается;
   деньги — целые гривны `int`). Меняешь продуктовое правило → обнови `PRODUCT.md`.
2. Отредактируй `prisma/schema.prisma`.
3. `npm run db:migrate` — создать и применить миграцию (dev). Дай миграции
   осмысленное имя.
4. `npm run prisma:generate` — ОБЯЗАТЕЛЬНО, перегенерить клиент в `generated/prisma/`.
5. Проверь, что импорты типов/enum'ов ссылаются на `generated/prisma/client` и
   `generated/prisma/enums` (относительный путь от файла, считай глубину `../`).
   НЕ меняй адаптер `@prisma/adapter-pg` на дефолтный PrismaClient.
6. Обнови затронутые сервисы и их `*.spec.ts` под новую схему.
7. Если добавил поле, которое надо заполнять при старте — обнови `prisma/seed.ts`.

Завершение: `npm run lint && npm test`. Покажи дифф schema.prisma и имя миграции.

НЕ редактируй вручную сгенерённые файлы в `generated/prisma/` — они перетираются.
